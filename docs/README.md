## 项目定位

- **一句话描述**：个人记账软件，核心价值是**适配并接管其他记账软件（一木、昼虎、钱迹）的数据库文件**，让用户可以无缝迁移数据到自己掌控的软件中。
- **核心目标**（按优先级）：
  1. 完整、准确导入三家第三方软件的 SQLite 数据库
  2. 资产（账户 + 余额 + 快照 + 趋势）管理体验对标主流记账软件
  3. 三端一致（Web / Android / iOS），数据本地自持
- **数据安全**：所有数据默认保存在本地（IndexedDB / SQLite），不依赖任何云服务。
