## 1. 记账模块

### 1.1 账单类型

| 类型 | 说明 |
|------|------|
| expense | 支出，从 `accountId` 账户扣款 |
| income | 收入，入 `accountId` 账户 |
| transfer | 转账，`accountId` 转出 → `incomeAccountId` 转入 |

### 1.2 核心交互

- **分类选择**：单分类（父类/子类两级）。首次点父类选中默认子类（`defaultSelect`），再次点击可选中父类本身。
- **金额键盘**：自定义计算器键盘，支持运算与快捷金额。
- **账户选择**：新建账单自动带出默认账户（`preference.defaultExpenseAccountId` / `defaultIncomeAccountId`），需校验账户属于当前账本。
- **多币种记账**：选择外币时记录当时汇率关系（`bill.currency`），显示时按当前汇率换算。
- **智能预测**：基于历史账单的线性回归模型，新增时预测分类与备注。
- **语音记账 / 自然语言识别**：AI 解析"买咖啡 25 元" → 金额、分类、备注。
- **附件与定位**：图片、位置（高德地图）。

### 1.3 余额联动规则（自动）

| 操作 | 余额变化 |
|------|---------|
| 新增支出 | `accountId.currentBalance -= amount` |
| 新增收入 | `accountId.currentBalance += amount` |
| 新增转账 | `accountId -= amount`，`incomeAccountId += amount` |
| 删除账单 | 反向撤销上述影响，并将相关快照 `isValid=false` |
| 修改账单 | 先撤销旧账单影响，再应用新账单影响；失效旧快照、创建新快照 |

> 跨币种场景：先按 `bill.currency` 换算成账户币种后再变动余额。

## 2. 账户管理

### 2.1 账户列表页

- 顶部：**总资产卡片**（按本位币折算），可展开查看资产构成明细。
- 账户按三大类分组展示：资金账户 / 记录账户 / 债务账户。
- 每个账户卡片：图标、名称、币种、当前余额、初始余额；`includeInAssets=false` 的账户半透明并标注"不计入总资产"。
- 「修复一致性」按钮：从 GlobalMeta 重新同步账户数据。

### 2.2 账户表单

字段：名称、三大类（fund/record/debt）、类型（alipay/wechat/bank/cash/credit/investment/other）、初始余额、币种、备注、是否计入总资产、银行图标。

扩展字段（信用卡）：信用额度、卡号、账单日、还款日。

校验：同一账本内账户名称不可重复。

### 2.3 手动调账（核心交互）

用户编辑账户余额时：

1. 计算差值 `diff = newBalance - currentBalance`
2. 若 `diff ≠ 0`，自动创建调账账单（`extra.isAdjustment = true`，分类为 `balance_adjustment_income` / `balance_adjustment_expense`，备注默认"手动调整余额"）
3. 更新 `currentBalance`

设计目的：保留调整历史、流水完整、可追溯。

### 2.4 余额快照

- 自动快照：每次记账 / 转账 / 调账生成（type 1-5）。
- 历史快照：用户手动为某账户添加某个时间点的余额（type 6），用于趋势图回溯。
- 删除 / 修改账单 → 关联快照 `isValid=false`（不物理删除）。
- 快照是趋势图的唯一数据源（见算法文档）。

### 2.5 账户合并

- 用于导入第三方数据后，将「同名账户」合并为一个。
- 合并时迁移：关联账单的 `accountId` / `incomeAccountId`、快照、GlobalMeta 中的 transfers/lends/reimbursements/instalments。
- 源账户删除，目标账户保留当前余额与初始余额。

### 2.6 账户删除

- **不删除关联账单**，仅将账单的 `accountId` / `incomeAccountId` 置空。
- 删除账本时级联删除属于该账本的账户。

## 3. 资产趋势

### 3.1 趋势图

- **总资产趋势**：按快照汇总所有计入资产的账户余额（按本位币折算），支持 按天 / 按周 / 按月 粒度。
- **单账户趋势**：选中账户的余额曲线。
- **跨年标记**：每年 1 月 1 日自动绘制虚线标记。
- **动态 Y 轴**：数据变化 <5% 时以均值为中心展示 ±10% 范围，避免曲线"贴地"。

### 3.2 资产构成（点击趋势图任意点）

展示该时间点的资产构成：每个账户名 + 折算后金额 + 原始币种金额，按金额降序。自动过滤"该时点尚未创建"的账户（依据 `createdAt` 与最早快照时间）。

### 3.3 统计信息

| 维度 | 说明 |
|------|------|
| 当前总资产 / 当前余额 | 权威值 |
| 期间变化 | 期末 - 期初 |
| 最高值 / 最低值 | 期间内 |
| 平均日/周/月存款、支出、收入 | 按粒度 |

### 3.4 高级统计

| 指标 | 公式 |
|------|------|
| 收支比 | 收入 / 支出 |
| 储蓄率 | (收入 - 支出) / 收入 |
| 最大回撤 | max(峰值 - 谷值)，展示金额与百分比 |
| 波动率 | 日收益率标准差 |
| 涨跌次数 | 相邻趋势点涨/跌计数 |

## 4. 多币种

- **本位币**：默认 CNY，可在设置中修改。
- **汇率源**：内置汇率表（`exchange-rates.json` 格式），不依赖外部网络请求。
- **手动覆盖**：用户可在币种管理页手动调整汇率，覆盖值按账本持久化（`currencyOverrides`）。
- **换算公式**：`convert(amount, from, to) = amount * (rate[to] / rate[from])`（以 baseCurrency=CNY 为锚）。
- **账户币种**：每个账户可设独立币种，总资产按本位币折算汇总。
- **记账币种**：账单记录当时的 `base/target/amount`，展示时按当前汇率换算。

---

## 5. 多账本

- 每个账本（Book）= 一个独立数据库（`book-<id>`），账单/账户/分类/标签/预算完全隔离。
- 首次启动自动创建默认账本「我的账本」。
- 切换账本：重建数据源并重新加载（上一代通过 `location.reload`，Flutter 版直接切换 Provider 数据源）。
- 删除账本：级联删除该账本下所有数据（含账户、快照）。

## 6. 第三方数据导入

### 6.1 支持的软件与文件

| 软件 | 数据库文件 | 解析器 |
|------|-----------|--------|
| 一木记账 | `Custom.db`（SQLite） | yimu parser |
| 昼虎记账（money+） | SQLite db | zhouhu parser |
| 钱迹 | SQLite db | qianji parser |

### 6.2 导入流程（统一链路）

```
选择 .db 文件
  → SQL 解析（读取全部相关表，过滤 delete_lpcolumn=1 的软删记录）
  → 数据映射（第三方表结构 → XuPurse 实体，金额 *10000）
  → 差异计算（基于上次导入的 ID 映射，识别 新增/删除/变更）
  → 预览确认（展示统计：账户/分类/标签/账单/转账/借贷…）
  → 同名账户合并候选确认
  → 写入账本（meta 一次写入 + 账单批量写入，不触发余额自动加减）
```

### 6.3 一木记账导入明细

解析表：accountbook / asset / parentcategory / childcategory / tag / bill / bill_tags / transfer / lend / budget / assethistory / refund / reimbursement / instalment。

映射规则：
- `asset.assetnumber` → `Account.currentBalance`（权威值）
- 分类：`parentcategoryid` → 父类，`childcategoryid` → 子类
- 账单：`billtype == 1` 收入，否则支出
- 金额统一 `*10000` 转万分之元
- Transfer / Lend / Refund / Reimbursement / Instalment 转成对应 Bill 参与余额与统计，原始元数据保留在 GlobalMeta
- `assethistory` → BalanceSnapshot
- ID 映射表 `yimuMapping` 保证**重复导入不产生重复数据**（diff 识别）

### 6.4 昼虎记账导入明细

解析表：account_book / account / category / bill / account_change_log / budget。

特点：`account_change_log` → BalanceSnapshot；`notProperty` 字段对应是否计入总资产；转账号单通过 `transferToId` 识别。

### 6.5 钱迹导入明细

解析表：account_book / account / category / bill。

特点：账单类型 `0=支出 1=收入 2=转账 7=债权债务`；`extra` JSON 字段承载报销/退款/手续费/多币种信息；账户 `type 1=资产 5=债务`。

### 6.6 同名账户合并

- 归一化账户名（去空格、括号、银行卡尾号等）后分组。
- 若新旧账户**账单时间范围不重叠** → 建议自动合并。
- 若重叠 → 标记冲突，由用户确认。

### 6.7 导入注意事项

- 首次导入建议使用**覆盖模式**（overlap），清空原数据重写。
- 导入不触发余额自动加减（`currentBalance` 由第三方权威值决定）。
- 导入的账单打标 `extra.isYimu / isZhouhu / isQianji = true`，余额重算时跳过，避免重复累加。

## 7. 分类 / 标签 / 预算

### 7.1 分类

- 内置默认分类（支出/收入两组，二级结构），硬编码在 `category.dart`。
- 自定义分类存入 GlobalMeta，`customName = true`。
- 调账专用分类：`balance_adjustment_income` / `balance_adjustment_expense`。

### 7.2 标签

- 自定义标签，可分组；账单可挂多个标签。
- 标签可设置 `preferCurrency`（选中该标签自动切换记账币种）。

### 7.3 预算

- 预算按分类 + 时间周期定义。
- 首页顶部预算卡片横向滑动展示，实时进度。
- 金额存储与显示统一「元」为单位的换算（避免上一代的单位混乱 bug）。

## 8. 搜索与统计

### 8.1 搜索

- 多条件筛选：时间范围、分类、标签、创建者、币种、金额区间、类型（收支/转账）、备注关键词。
- **模糊搜索**：关键词匹配备注/标签，支持范围限定（全部 / 备注 / 标签 / 金额）。
- 搜索结果支持批量编辑、批量删除。

### 8.2 搜索结果分析页

- 按筛选结果绘制趋势图（收入/支出/结余曲线）、分类占比、标签词云。
- 时间范围 / 粒度 / 关注类型（支出、收入）可切换。

### 8.3 统计页

- 月度/年度收支对比、分类占比饼图、每日柱状图、预算执行情况。
- 地图消费足迹（高德地图，需配置 API Key；不在 v1 范围）
