## 历史阶段记录（上一代 cent-xyx）

> 以下为上一代 React 实现（cent-xyx）的关键演进，供重写时参考与对标。**XuPurse 从 0 重写，不在本仓库代码中体现这些提交**，仅作为设计依据。

### 阶段摘要

| 阶段 | 内容 |
|------|------|
| 账户体系 0→1 | 三大类账户（fund / record / debt）、账户表单与列表、Bill 增加 `accountId` / `incomeAccountId` |
| 币种 | 账户币种、内置汇率表 + 手动覆盖、换算公式修复 |
| 快照机制 | BalanceSnapshot、自动快照、历史快照、快照失效 |
| 逻辑迭代 | `currentBalance` 权威值、调账账单、余额重算、剔除云同步 |
| 黄金资产 | 黄金资产类型与扩展字段 |
| 第三方适配 | 一木 → 昼虎 → 钱迹 的 SQLite 解析 + 映射 + diff 导入 |
| 账户合并 | 同名账户合并候选检测与迁移 |
| 趋势统计 | 总资产趋势、资产构成、动态 Y 轴、高级统计（收支比/储蓄率/最大回撤/波动率） |
| 预算搜索 | 预算修复、搜索模糊匹配、搜索结果分析页 |
| AI 与同步 | AI 助手、多设备局域网同步、PWA 优化 |

### 主要设计决策（重写时沿用）

1. **余额权威值**：`currentBalance` 为用户矫正后的权威值，总资产直接使用，不以账单反推。
2. **调账账单**：手动改余额自动生成 `isAdjustment=true` 账单，保留历史。
3. **快照为趋势唯一数据源**：趋势图基于快照 + 二分查找，避免 O(n²)。
4. **导入幂等**：持久化 ID 映射 + diff，重复导入不产生重复数据。
5. **导入不触发余额加减**：以第三方权威值覆盖，导入账单打来源标记，重算时跳过。
