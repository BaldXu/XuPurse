# XuPurse

个人记账软件，核心价值是**适配并接管其他记账软件（一木、昼虎、钱迹）的数据库文件**，让数据无缝迁移到自己掌控的软件中。

- Flutter 实现，支持 **Android / iOS / Web / Windows** 四端
- 数据全部保存在本地（SQLite / IndexedDB），不依赖任何云服务
- 当前版本：**v0.3.0**

## ✨ 已支持功能

- **记账**：日常收支、转账（含手续费）、调账、余额快照与资产趋势
- **退款**：支出可部分 / 多次退款，退款回补到原账户并自动冲抵统计
- **账户**：资金 / 记录 / 负债三类账户、账户合并、历史快照、多账本
- **多币种**：内置汇率 + 手动覆盖 + **AI 一键更新汇率**
- **统计**：收支汇总、分类占比（一级 / 叶子两级粒度）、趋势、预算执行、标签分析、年度汇总报告；统计页 **AI 助手**基于本机账单随问随答
- **搜索**：账单模糊搜索 + 搜索结果分析
- **第三方导入**：一木 / 昼虎 / 钱迹 `.db` 文件高保真导入（解析 → 映射 → diff → 预览 → 幂等合并）
- **备份与恢复**：全量备份（全部账本 + 应用设置），可选加密（Argon2id + AES-256-GCM），支持覆盖 / 追加两种恢复方式
- **定时备份**：任务式定时备份，距上次 ≥24 小时自动执行；**可自选保存目录**（Android 走 SAF，能写到 SD 卡 / 任意文件夹，卸载 App 也不丢）、文件名带时间戳且只保留最近 5 份、支持加密、支持「立即备份」手动触发一次而不影响定时节奏；失败会在备份页显示原因
- **自定义**：主题 / 卡片样式 / 磨砂玻璃 / 图标包（简约 · Twitter 表情）/ 屏幕旋转（默认固定竖屏，可跟随系统）

## 📱 数据安全

- 备份默认落在应用沙箱之外（Android 默认 `Download/XuPurse/`，可改为任意自选目录），卸载或清数据不会连带删掉备份
- 定时备份文件名形如 `xupurse_auto_20261027_143659.json`，手动备份为 `xupurse_backup_<时间戳>.json`；**自动轮换只清理定时备份，绝不碰手动备份**

## 🚀 本地开发

```bash
flutter pub get
flutter run                  # 默认设备运行
flutter run -d chrome        # Web
flutter build apk --release  # Android 正式包
flutter build windows        # Windows 桌面端
flutter analyze && flutter test
```

> 真机覆盖安装（**不会卸载**、保留数据）：`bash tool/install_phone.sh <设备序列号>`
