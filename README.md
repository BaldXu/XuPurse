# XuPurse

个人记账软件，核心价值是**适配并接管其他记账软件（一木、昼虎、钱迹）的数据库文件**，让数据无缝迁移到自己掌控的软件中。

- Flutter 实现，支持 **Web / Android / iOS** 三端
- 数据全部保存在本地（IndexedDB / SQLite），不依赖任何云服务
- 当前版本：**v0.1.1**

## ✨ 已支持功能

- **记账**：日常收支、转账（含手续费）、调账、余额快照与资产趋势
- **账户**：资金 / 记录 / 负债三类账户、账户合并、历史快照、多账本
- **多币种**：内置汇率 + 手动覆盖 + **AI 一键更新汇率**
- **统计**：收支汇总、分类占比、趋势、预算执行、标签分析；统计页 **AI 助手**基于本机账单随问随答
- **搜索**：账单模糊搜索 + 搜索结果分析
- **第三方导入**：一木 / 昼虎 / 钱迹 `.db` 文件高保真导入（解析 → 映射 → diff → 预览 → 幂等合并）
- **备份**：数据导出 / 导入（JSON + 压缩）
- **自定义**：主题 / 卡片样式 / 磨砂玻璃 / 图标包（简约 · Twitter 表情）

## 🚀 本地开发

```bash
flutter pub get
flutter run                  # 默认设备运行
flutter run -d chrome        # Web
flutter build apk --release  # Android 正式包（签名配置见 docs/deployment.md）
```
